# 备份与恢复说明

Lineup 笔记没有服务器，所有 Lineup、类型和图片都保存在**你当前使用的浏览器**里。这份说明介绍怎样备份这些数据，以及出问题时怎样恢复。

> 最省心的做法：在电脑上用 Edge 或 Chrome 开启一次**自动备份到文件夹**，并把这个文件夹放在网盘的同步目录里。

---

## 一、为什么需要备份

数据保存在浏览器的「网站数据」（IndexedDB）里，不是普通的缓存。下面这些操作**不会**删除数据：

- 关闭网页、关闭浏览器、重启电脑
- 在浏览器的「清除浏览数据」里只清除「缓存的图片和文件」
- 网站更新

下面这些操作**会**删除数据：

- 在「清除浏览数据」里勾选了「**Cookie 和其他网站数据**」
- 360、电脑管家等软件的「清理浏览器痕迹 / 隐私」功能
- 重置或卸载浏览器、重装系统
- 在无痕 / InPrivate 窗口里记录（关闭窗口数据就没了）

另外，**不同浏览器、不同电脑、不同网址之间的数据互不相通**。例如本地开发地址 `http://localhost:5173` 和 GitHub 上的网址，是两份独立的数据。

## 二、方式一：自动备份到文件夹（推荐）

开启后，每次新增、修改、删除 Lineup，网站都会在几秒后自动把**全部数据（包括图片）**保存到你电脑上的一个文件夹。

> 需要**电脑上的 Edge 或 Chrome**。手机、Firefox、Safari 暂不支持，请使用下面的「手动导出」。

### 开启步骤（只需要做一次）

1. 在电脑上用 Edge 或 Chrome 打开网站。
2. 点左下角「**设置**」→「**数据备份**」，找到「**自动备份到文件夹**」，点「**选择备份文件夹**」。
3. 在弹出的窗口里**新建一个专用文件夹**并选中它，例如 `D:\Lineup备份`，然后点「选择文件夹」。
   - 浏览器不允许直接选择「桌面」「文档」「下载」或磁盘根目录（如 `D:\`）本身，请选它们下面的子文件夹。
   - 如果电脑上装了 OneDrive、坚果云、百度网盘等同步软件，建议把文件夹建在它的**同步目录**里，这样还会自动多一份云端副本。
4. 浏览器询问「是否允许此网站编辑文件」时，点「**编辑文件**」或「**允许**」。
5. 看到「已开启自动备份」的提示就完成了。导览栏底部会显示「**已自动备份 · 时间**」。

### 开启之后

- **什么时候备份**：新增、修改、删除 Lineup 或类型，以及导入备份后，大约 3 秒自动备份一次；切换到其他标签页、最小化浏览器或关闭网页前，也会尽快补上还没备份的修改。
- **备份文件**：文件夹里会出现 `lineup-auto-2026-09-28.zip` 这样的文件。
  - **每天一个文件**，当天的每次修改都会更新当天的文件。
  - 每个 zip 都包含当时的**全部**数据，任意一个都可以单独用来恢复。
  - 默认保留**最近 7 天**（指有修改的 7 天），更早的自动备份会被自动删除。可以在设置里改成 3 / 14 / 30 天或全部保留。
- **说明文件**：`lineup-backup-README.txt`，里面写了这些文件是什么、怎么恢复。
- **手动导出的备份**（`lineup-backup-日期-时间.zip`）也可以放进这个文件夹，它们会出现在设置的备份列表里，但**不会被自动删除**。
- **安全保护**：网站里一个 Lineup 都没有时不会写入备份，不会用空数据覆盖以前的备份。

### 状态怎么看

导览栏最底部有一行备份状态，点它可以直接打开「设置 → 数据备份」：

| 显示 | 含义 | 需要做什么 |
| --- | --- | --- |
| 已自动备份 · 14:32 | 最新数据已经备份 | 不需要 |
| 有修改，稍后自动备份 / 正在自动备份… | 几秒内会完成 | 不需要 |
| 自动备份待授权 · 点击处理 | 浏览器需要你再次允许访问文件夹 | 点页面顶部黄色提示里的「允许访问」 |
| 自动备份失败 · 点击查看 | 文件夹被移动 / 删除，或写入出错 | 按提示「重新选择文件夹」或「重试」 |
| 未开启自动备份 · 点击设置 | 还没开启 | 按上面的步骤开启 |

### 关于「允许访问」

出于安全考虑，浏览器有时会在你重新打开网站后，要求再次确认是否允许网站访问备份文件夹。这时页面顶部会出现黄色提示：

> 有修改还没备份：请允许网站访问备份文件夹「Lineup备份」 **[允许访问]**

点「允许访问」后，浏览器会弹出确认窗口。如果里面有「**每次访问时都允许**」，请选它，以后就不用再点了。

## 三、方式二：手动导出

适合手机、不支持自动备份的浏览器，或者想在大改之前留一份快照。

1. 「设置」→「数据备份」→「手动备份与恢复」→「**导出备份**」。
2. 浏览器会下载一个 `lineup-backup-20260928-1430.zip`，把它保存到安全的地方（网盘、U 盘等）。

设置页会显示「上次导出」的时间，方便你判断是不是该再导出一次了。

## 四、如何恢复

所有恢复操作最后都会显示备份的内容（导出时间、多少个 Lineup、图片等），确认后再选「**合并导入**」或「**覆盖现有数据**」：

| | 合并导入 | 覆盖现有数据 |
| --- | --- | --- |
| 网站现有、备份里没有的 Lineup | 保留 | 删除 |
| 备份里有、网站现在没有的 Lineup | 恢复回来 | 恢复回来 |
| 两边都有的同一个 Lineup | 变成备份里的版本 | 变成备份里的版本 |
| 类型 | 同名类型自动合并，不会重复 | 完全换成备份里的类型 |
| 适合 | 大多数情况 | 想让网站完全回到备份时的样子 |

### 情况 A：浏览器数据被清掉了、重装了浏览器（同一台电脑）

1. 打开网站，这时里面是空的。
2. 「设置」→「数据备份」→「**选择备份文件夹**」，选**原来的备份文件夹**。
3. 网站发现文件夹里有备份，会问「要从这份备份恢复吗？」→ 点「**恢复这份备份**」。
4. 下方出现备份信息，点「**合并导入**」。
5. 完成：数据恢复了，自动备份也重新开启了。

### 情况 B：换电脑、换浏览器，或者从本地地址换到 GitHub 上的网址

1. 在新的地方打开网站。
2. 「设置」→「数据备份」→「手动备份与恢复」→「**选择备份文件**」，选最新的备份 zip（自动备份文件夹里日期最新的 `lineup-auto-…zip`，或者手动导出的文件）。
3. 点「**合并导入**」。
4. 在新的地方重新开启一次自动备份。

### 情况 C：误删了 Lineup，或者改错了

1. 「设置」→「数据备份」→「自动备份到文件夹」→「**文件夹中的备份**」，找到**出错之前那一天**的备份，点「**恢复**」。
2. 在下方确认备份内容：
   - 想找回误删的 Lineup，同时保留之后新建的：选「**合并导入**」。
     注意：两边都有的 Lineup 会变回备份里的版本，所以如果那之后还修改过其他 Lineup，这些修改会被还原。
   - 想让所有数据回到那一天的样子：选「**覆盖现有数据**」。

> 提示：当天的自动备份会随着修改不断更新。如果今天改错了东西，要恢复的是**前一天**的文件；如果担心，可以在大改之前先手动导出一份。

### 在手机上查看

手机浏览器不支持自动备份。可以把电脑上导出的 zip 发到手机，在手机浏览器打开网站，用「选择备份文件」导入。

## 五、常见问题

**点「选择备份文件夹」提示不支持，或者没有这个按钮？**
需要电脑上的 Edge 或 Chrome（其他基于 Chromium 的浏览器通常也可以）。手机、Firefox、Safari 请用手动导出。

**提示「无法打开此文件夹」或「此文件夹包含系统文件」？**
浏览器不允许直接选择桌面、文档、下载或磁盘根目录本身。在选择窗口里点「新建文件夹」，选中新建的子文件夹即可。

**备份文件夹可以移动或改名吗？**
可以。之后网站会提示「找不到备份文件夹」，点「**重新选择文件夹**」，选移动后的位置就行。

**备份文件越来越大？**
主要是截图占空间。上传图片时默认会压缩（「设置 → 显示与图片」），通常一张截图只有几百 KB。也可以把保留天数改少一些。

**本地地址（localhost）和 GitHub 上的网址能用同一个备份文件夹吗？**
不建议。两边都会写入同名的 `lineup-auto-日期.zip`，会互相覆盖当天的备份。平时只在一个地址上记录，另一个地址需要数据时用「选择备份文件」导入即可。

**「清空所有数据」之后，自动备份为什么关了？**
这是保护措施：清空后自动备份会同时关闭，避免新的少量数据覆盖文件夹里的旧备份。备份文件夹里已有的文件不会被删除，需要时可以重新选择文件夹并恢复。

**自动备份会不会让网站变卡？**
备份在后台进行，一般一两秒内完成，不影响正常使用。数据很多（几百个带图片的 Lineup）时会稍慢一些。
